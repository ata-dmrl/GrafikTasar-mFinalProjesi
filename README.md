# React Type - React Öğreten Web Sitesi
Frontend ve Backend di React Typescript dilinde yazılan ,React dilini hem videolu anlatımla hemde kod örnekleri ile anlatan web sitemiz react dilini öğretmektedir.
Proglamlama dilini öğretirken sadece öğretmek değil diğer kullanıclar ile etkilişem girebilmesi onlar ile rekabet etmesi ve onlarla tanışıp proje geliştirmeleri içinde belirli alanlar içermektedir.

## React Type
``` Bash
cd frontend
npm run dev
```
```Bash
cd backend
npm run dev
```
